Installing on Android

The app downloads from this page rather than Google Play, so Android asks for permission the first time.

  1. Open this page on your Android phone or tablet and tap Download for Android. The file is 120 MB, so Wi-Fi is best. If the browser warns about the file type, choose to download it anyway.
  2. Open the downloaded file. If Android asks, allow your browser to install unknown apps.
  3. Tap Install. Google Play Protect may ask you to confirm, because the app doesn't come from Google Play.
  4. Open Oxx Report from your home screen or app drawer.

To update, download the new version from this page and install it over the old one.
